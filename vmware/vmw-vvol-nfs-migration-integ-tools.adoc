= VMware 환경의 NFS 데이터스토어용 ONTAP 통합 툴
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere, NFS VAAI 플러그인, SnapCenter Plug-in for VMware vSphere 등 VMware 환경에서 NFS 데이터스토어를 관리, 모니터링 및 보호하기 위한 ONTAP 통합 툴에 대해 알아보십시오.

NetApp은 VMware 환경에서 NFS 데이터스토어를 관리하고 보호하기 위해 다음과 같은 툴을 제공합니다:

* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/index.html["ONTAP tools for VMware vSphere"^]*: ONTAP 관리를 vSphere Client에 통합하여 NFS 데이터스토어의 프로비저닝, 모니터링 및 관리를 수행하고 권장 ESXi 호스트 설정을 적용합니다.
* *link:https://docs.netapp.com/us-en/nfs-plugin-vmware-vaai/index.html["VMware VAAI용 NetApp NFS 플러그인"^]*: 클론 생성 등 스토리지 작업을 ONTAP으로 오프로드하여 성능을 향상시키고 ESXi 호스트의 부하를 줄입니다.
* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/enable-storage-replication-adapter.html["스토리지 복제 어댑터(SRA)"^]*: ONTAP SnapMirror 복제를 사용하여 재해 복구를 오케스트레이션하기 위해 VMware Live Site Recovery(이전의 VMware Site Recovery Manager)와 통합됩니다.
* *link:vmw-dr-gs.html["NetApp Disaster Recovery"]*: NetApp Console에서 NFS 데이터스토어에 있는 VM의 재해 복구를 오케스트레이션합니다.
* *link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/index.html["SnapCenter Plug-in for VMware vSphere"^]*: NFS 데이터스토어의 VM에 대해 크래시 일관성 및 VM 일관성 백업 및 복원을 제공합니다.
* *link:https://docs.netapp.com/us-en/data-infrastructure-insights/index.html["NetApp Data Infrastructure Insights"^]*: ONTAP 스토리지 및 VMware 인프라의 성능과 상태에 대한 가시성을 제공합니다.


이러한 툴은 VMware 환경에서 NFS 데이터스토어의 운영을 간소화하고 성능을 향상시키며 데이터 보호 기능을 제공합니다.
