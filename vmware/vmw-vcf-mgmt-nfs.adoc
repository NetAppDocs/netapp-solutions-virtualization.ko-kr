= vCenter 서버 인스턴스를 NFS 데이터스토어를 사용하는 VCF 관리 도메인으로 통합하기 위한 배포 워크플로
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
기존 vSphere 클러스터와 NetApp ONTAP NFS 데이터스토어를 VMware Cloud Foundation 관리 도메인으로 통합합니다. 구성 요구 사항을 검토하고, ONTAP 툴을 배포하고 NFS 데이터스토어를 프로비저닝하고, VCF Installer Tool을 사용하여 기존 구성 요소를 검증 및 사용하고, 필요한 새 구성 요소를 배포하고, 플랫폼을 구성합니다.

이 워크플로는 ONTAP NFS 4.1 데이터스토어를 VCF 관리 도메인의 주 스토리지로 사용하는 경우에도 적용할 수 있습니다.

통합 프로세스에 대한 개요는 VMware 설명서를 참조하십시오: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["기존 가상 인프라를 VCF로 통합하기"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"]link:vmw-vcf-mgmt-nfs-requirements.html["구성 요구 사항을 검토하세요"]
[role="quick-margin-para"]
NFS 데이터스토어를 사용하여 vCenter 서버 인스턴스를 VCF 관리 도메인으로 통합하기 위한 주요 요구 사항을 검토하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"]link:vmw-vcf-mgmt-nfs-deploy.html["ONTAP 도구 배포 및 NFS 데이터 저장소 프로비저닝"]
[role="quick-margin-para"]
ONTAP tools for VMware vSphere 배포하고 NFS 데이터 저장소를 프로비저닝합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["삼"]link:vmw-vcf-mgmt-nfs-converge.html["vSphere 클러스터를 VCF 관리 도메인으로 통합"]
[role="quick-margin-para"]
VCF Installer Tool을 사용하여 VCF 관리 도메인을 구성하는 기존 구성 요소를 검증하고 재사용하며 새 구성 요소를 배포할 수 있습니다.
