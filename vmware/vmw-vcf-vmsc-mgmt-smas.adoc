= SnapMirror Active Sync(SAN 및 NAS)를 사용하여 VCF 관리 도메인용 스트레치 클러스터를 구성합니다.
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
이 사용 사례에서는 ONTAP tools for VMware vSphere 사용하여 VCF 관리 도메인에 대한 스트레치 클러스터를 구성하는 절차를 설명합니다.  이 절차에는 vSphere 호스트와 vCenter Server 배포, ONTAP 도구 설치, SnapMirror Active Sync를 사용한 데이터 저장소 보호, 보호된 데이터 저장소로 VM 마이그레이션, 보조 스토리지 구성이 포함됩니다.

image:vmw-vcf-vmsc-mgmt-smas-001.png["VCF 관리 도메인을 위한 ONTAP 사용한 Stretch Cluster"]

SAN의 경우 균일 및 비균일 확장 클러스터 구성이 모두 지원됩니다. NAS의 경우 ONTAP 9.19.1에서는 액티브-패시브 구성이 지원됩니다.

[NOTE]
====
호스트 근접성 설정은 다중 경로 구성에서 스토리지 트래픽에 대한 최적 경로 선택을 보장하는 데 사용됩니다.  호스트 근접성 설정은 SCSI의 경우 igroup에서, NVMe-oF의 경우 서브시스템에서 구성됩니다.  예를 들어, 균일 호스트 액세스 구성에서 호스트는 확장 클러스터의 두 스토리지 시스템 모두에 액세스할 수 있습니다.  다중 경로 구성에서 최적 경로와 비최적 경로는 호스트 근접성 설정을 기반으로 구성됩니다.

====


[[scenario-overview]]
== 시나리오 개요

확장 클러스터 솔루션은 기본 클러스터 또는 VCF 관리 도메인이나 워크로드 도메인의 추가 클러스터에 구현할 수 있습니다. ONTAP 툴 10.6은 iSCSI 및 FC 프로토콜을 사용하는 VMFS 데이터스토어에 대해 SnapMirror 액티브 싱크를 통한 데이터스토어 보호를 지원합니다. ONTAP는 SAN(iSCSI, FC, NVMe-oF) 및 NAS(NFS v3 및 NFSv4.1)에 대해 SnapMirror 액티브 싱크를 지원합니다. SAN 프로토콜의 경우 보호는 일관성 그룹 수준에서 수행되고, NAS의 경우 SVM 수준에서 수행됩니다. 다음 다이어그램은 FC를 사용하는 VMFS용 ONTAP tools를 이용한 VCF 관리 도메인의 확장 클러스터 솔루션을 보여줍니다.

image:vmware-vcf-asa-mgmt-stretchcluster-002.png["VCF 관리 도메인을 위한 ONTAP 사용한 Stretch Cluster"]

.관리 도메인의 주 저장소
[%collapsible%open]
====
. 지원되는 프로토콜을 사용하여 VCF 관리 도메인을 배포하십시오.
+
.. FC 기반 VMFS 및 NFSv3의 경우 VCF 설치 툴을 직접 사용합니다. iSCSI, NVMe-oF 및 NFSv4.1의 경우 vCenter로 설정한 후 VCF 설치 툴을 사용하여 관리 도메인을 배포해야 합니다. 자세한 내용은 link:vmw-vcf-migrate.html["iSCSI, NVMe-oF 및 NFSv4.1을 사용한 VCF 관리 도메인 배포"]을 참조하십시오.


. ONTAP tools for VMware vSphere 배포
. VMware vSphere용 SnapCenter 플러그인 배포(선택 사항)
. 데이터 저장소를 보호합니다.
+
.. iSCSI 및 FC의 경우, 데이터스토어를 보호하기 위해 ONTAP tools 10.6 이상을 사용합니다. NVMe-oF 및 NFSv4.1의 경우, System Manager를 사용하여 데이터스토어를 보호합니다. NVMe/TCP 및 NFS에 대한 참조로 아래 비디오 데모를 확인하십시오.




====
.관리 도메인의 추가 스토리지
[%collapsible%open]
====
관리 도메인이 구축되고 실행되면 ONTAP tools 10.6 이상 버전을 사용하여 추가 데이터스토어를 생성하고 iSCSI 및 FC용 SnapMirror 액티브 동기화로 보호할 수 있습니다. NVMe-oF 및 NFS의 경우 아래 비디오 데모를 참조하십시오. 데모는 워크로드 도메인에서 진행되지만 관리 도메인에서도 동일한 단계를 따를 수 있습니다.
