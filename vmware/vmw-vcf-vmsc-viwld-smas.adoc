= SnapMirror 액티브 동기화(SAN 및 NAS)를 사용하여 워크로드 도메인에 대한 스트레치 클러스터 구성
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
이 사용 사례에서는 ONTAP tools for VMware vSphere와 함께 SnapMirror active sync를 사용하여 워크로드 도메인용 스트레치 클러스터를 구성하는 절차를 설명합니다(ONTAP 툴 10.6은 FC 및 iSCSI를 지원함). ONTAP은 SAN(iSCSI, Fibre Channel 및 NVMe over Fabrics 사용) 및 NAS(NFSv3 및 NFSv4.1) 모두에 대해 SnapMirror active sync를 지원합니다.

image:vmw-vcf-vmsc-viwld-smas-001.png["SnapMirror active sync를 사용하는 VCF용 스트레치 클러스터"]

SAN의 경우 균일 및 비균일 확장 클러스터 구성이 모두 지원됩니다. NAS의 경우 ONTAP 9.19.1에서는 액티브-패시브 구성이 지원됩니다.

[NOTE]
====
호스트 근접성 설정은 다중 경로 구성에서 스토리지 트래픽에 대한 최적 경로 선택을 보장하는 데 사용됩니다.  호스트 근접성 설정은 SCSI의 경우 igroup에서, NVMe-oF의 경우 서브시스템에서 구성됩니다.  예를 들어, 균일 호스트 액세스 구성에서 호스트는 확장 클러스터의 두 스토리지 시스템 모두에 액세스할 수 있습니다.  다중 경로 구성에서 최적 경로와 비최적 경로는 호스트 근접성 설정을 기반으로 구성됩니다.

====


[[scenario-overview]]
== 시나리오 개요

VCF 워크로드 도메인의 데이터 저장소는 SnapMirror 액티브 싱크를 사용하여 보호함으로써 확장형 클러스터 솔루션을 제공할 수 있습니다. SAN의 경우 데이터 저장소 수준(일관성 그룹)에서 보호가 활성화되고, NAS의 경우 SVM 수준에서 보호됩니다.



[[prerequisites]]
== 필수 조건

.워크로드 도메인의 주 스토리지
[%collapsible%open]
====
워크로드 도메인은 VCF Ops 툴을 사용하여 가져오기 또는 생성 방식으로 만들 수 있습니다.

. 지원되는 프로토콜을 사용하여 워크로드 도메인을 생성합니다.
. link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-vcenter.html["vCenter 플러그인을 배포하려면 ONTAP 도구 관리자에 워크로드 도메인 vCenter를 등록하세요."]
. link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-storage-backend.html["ONTAP 도구에 저장 시스템 등록"]
. iSCSI 및 FC 데이터스토어에 대해서는 link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/protect-multiple-ds.html["vSphere 데이터스토어를 ONTAP tools로 보호합니다"]을 참조하십시오.
. NVMe-oF 및 NFS 데이터스토어의 경우, 아래 비디오 데모를 참조하여 SnapMirror 액티브 동기화를 사용하여 워크로드 도메인의 데이터스토어를 보호하는 단계를 확인하십시오.


====
.워크로드 도메인의 추가 스토리지
[%collapsible%open]
====
워크로드 도메인이 가동되어 실행되면 ONTAP tools를 사용하여 추가 데이터스토어를 생성하고 보호할 수 있습니다. SnapMirror 활성 동기화에 대한 자세한 내용은 다음을 참조하십시오. https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html#benefits["ONTAP SnapMirror active sync에 대해 알아봅니다"]


TIP: ONTAP tools 10.6 이상 버전에서는 SnapMirror 활성 동기화를 사용하여 워크로드 도메인의 데이터 저장소를 보호할 수 있습니다. 아래 비디오 데모를 참조하여 SnapMirror 활성 동기화를 사용하여 워크로드 도메인의 데이터 저장소를 보호하는 단계를 확인하십시오.

====
