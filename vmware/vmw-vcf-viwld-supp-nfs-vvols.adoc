= VCF 워크로드 도메인에 NFS vVols 데이터스토어를 보조 스토리지로 추가하기 위한 배포 워크플로

[role="lead"]
ONTAP tools for VMware vSphere를 사용하여 VCF 워크로드 도메인에 NFS vVols 데이터스토어를 보조 스토리지로 추가하는 방법을 시작해 보십시오. 배포 요구사항을 검토하고, ONTAP tools for VMware vSphere를 배포하고, SVM을 논리 인터페이스로 구성하고, 스토리지를 구성하게 됩니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"]link:vmw-vcf-viwld-supp-nfs-vvols-requirements.html["배포 요구 사항 검토"]
[role="quick-margin-para"]
VMware Cloud Foundation 관리 도메인에 NFS vVols 배포하기 위한 요구 사항을 검토합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"]link:vmw-vcf-viwld-supp-nfs-vvols-svm-lifs.html["SVM 및 LIF 생성"]
[role="quick-margin-para"]
NFS 트래픽을 위해 여러 개의 LIF가 있는 SVM을 생성합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["삼"]link:vmw-vcf-viwld-supp-nfs-vvols-network.html["네트워킹 구성"]
[role="quick-margin-para"]
vSphere 호스트에서 NFS용 네트워킹을 설정합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["네"]link:vmw-vcf-viwld-supp-nfs-vvols-storage.html["저장소 구성"]
[role="quick-margin-para"]
ONTAP 도구를 배포하고 사용하여 스토리지를 구성합니다.
