= VMFS 데이터스토어를 사용하는 VCF 관리 도메인으로 vCenter 서버 인스턴스를 통합하기 위한 배포 요구 사항
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
vSphere 클러스터와 NetApp ONTAP VMFS 데이터스토어를 VMware Cloud Foundation 관리 도메인으로 통합하기 위한 요구 사항을 검토하십시오.



[[infrastructure-requirements]]
== 인프라 요구 사항

다음 구성 요소와 구성이 제대로 되어 있는지 확인하세요.

* NetApp FC/iSCSI 트래픽을 허용하도록 구성된 스토리지 가상 머신(SVM)이 있는 ASA R2/ASA/AFF 스토리지 시스템.
* FC/iSCSI 트래픽을 전송하기 위해 생성된 논리 인터페이스(LIF)이며 SVM과 연결됩니다.
* FC 및 NVMe/FC의 경우 패브릭 스위치에서 FC 조닝이 구성됩니다.
* iSCSI 및 NVMe/TCP의 경우, 각각의 트래픽을 전송하도록 vSphere 호스트에 구성된 vmkernel 포트 그룹입니다.
* 지원되는 vSphere 클러스터(4개의 vSphere 호스트와 클러스터에 함께 배치된 vCenter 어플라이언스 포함)입니다.
* 이 목적으로 설정된 VLAN 또는 네트워크 세그먼트에서 vMotion을 위해 구성된 분산 포트 그룹입니다.
* VCF 통합에 필요한 VCF Installer 툴을 다운로드했습니다. 자세한 내용은  https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment.html["VCF 배포, 통합 및 업그레이드"]을 참조하십시오.
* ONTAP 도구의 전제 조건이 충족되었습니다.
+
ONTAP 도구의 필수 구성 요소에 대한 전체 정보는 다음을 참조하세요. https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/deploy/prerequisites.html#system-requirements["ONTAP tools for VMware vSphere 의 필수 구성 요소"] .

+
ONTAP tools for VMware vSphere HA 또는 비 HA 구성으로 설치할 수 있습니다.
