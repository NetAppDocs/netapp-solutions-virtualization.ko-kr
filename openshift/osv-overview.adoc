= Red Hat OpenShift Virtualization에 대해 알아보세요.
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Red Hat® OpenShift® Virtualization은 기업이 기존 가상 머신(VM)과 최신 워크로드를 통합된 하이브리드 클라우드 애플리케이션 플랫폼에서 원활하게 마이그레이션, 실행 및 관리할 수 있도록 지원합니다. OpenShift Virtualization은 모든 OpenShift 구독에 포함된 오퍼레이터로 제공됩니다. OpenShift Container Platform의 애드온인 이 솔루션은 VM과 컨테이너화된 애플리케이션을 통합하기 위한 강력한 솔루션을 제공합니다. 이 솔루션은 뛰어난 성능, 확장성 및 안정성으로 잘 알려진 신뢰할 수 있는 Linux 커널 하이퍼바이저인 KVM(Kernel-based Virtual Machine)을 사용하여 OpenShift 내에서 네이티브 오브젝트로 가상 머신에 대한 엔터프라이즈급 가상화를 제공합니다.

image:redhat-openshift-044.png["OpenShift 가상화"]



[[key-features-of-red-hat-openshift-virtualization]]
== Red Hat OpenShift Virtualization의 주요 기능

**하이브리드 워크로드:** 클라우드 네이티브의 이점을 누리면서 VM을 마이그레이션하고 실행하며, 통합 툴셋을 사용하여 컨테이너 및 서버리스 워크로드와 함께 관리합니다.

**점진적 현대화:** 기존 VM을 중단하지 않고 컨테이너 도입, 마이크로서비스 구현 또는 AI 통합을 통해 원하는 속도로 현대화를 진행하세요.

**Kubernetes 통합:** Kubernetes 사용자 지정 리소스를 활용하여 OpenShift 클러스터에 가상화 기능을 추가합니다.



[[capabilities-of-red-hat-openshift-virtualization]]
== Red Hat OpenShift Virtualization의 기능

**VM 관리:** Linux 및 Windows VM을 생성하고 관리합니다.

**통합 워크로드:** 클러스터 내에서 Pod 및 VM 워크로드를 동시에 실행합니다.

**연결성:** 다양한 콘솔 및 CLI 도구를 통해 VM에 액세스할 수 있습니다.

**VM 작업:** 노드 간 VM 가져오기, 복제 및 라이브 마이그레이션을 수행합니다.

**리소스 관리:** 가상 머신에 연결된 네트워크 인터페이스 및 스토리지 디스크를 관리합니다.



[[compatibility]]
== 호환성

OpenShift Virtualization은 개념적으로 VMware vSphere와 다르지만, 다음과 같이 친숙한 기능을 제공하여 가상화 관리자에게 특별히 맞춤화된 현대적인 플랫폼을 제공합니다. **Live Migration:** vSphere의 vMotion과 동일합니다.

**스토리지 관리:** OpenShift의 스토리지 클래스는 vSphere의 SPBM(Storage Policy Based Management)과 일치합니다.

**영구 스토리지:** 영구 볼륨 클레임(PVC)과 영구 볼륨(PV)은 vSphere의 데이터스토어에 해당합니다.
